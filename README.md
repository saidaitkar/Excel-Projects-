📊 Sales Analysis Dashboard – Excel

Welcome to my Sales Analysis Dashboard project. This project demonstrates how Microsoft Excel can be used to analyze sales data, track key performance indicators (KPIs), identify trends, and create an interactive dashboard for business decision-making.

🚀 About This Project

The Sales Analysis Dashboard transforms raw sales data into meaningful business insights using Excel. It provides an interactive view of sales performance across different products, regions, categories, and time periods.

The dashboard helps users quickly understand sales trends, revenue performance, and overall business performance through interactive charts, KPIs, and filters.
